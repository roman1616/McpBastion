# Changelog

All notable changes to this project are documented in this file.
The format is based on Keep a Changelog and the project adheres to Semantic Versioning.

## [1.0.0] - 2026-08-14

### Added
- 1.0 hardening: fuzzed parser inputs, zero-dependency TS console build.
- Anomaly flagging for unusual argument sizes and repeat calls.

### Changed
- Wildcard tool matching with explicit-deny precedence.

## [0.9.0] - 2026-02-27

### Added
- Demo sessions and the forward pipeline used for end-to-end testing.

## [0.8.0] - 2025-11-14

### Added
- Audit report export (markdown + JSON) with stable event IDs.

## [0.7.0] - 2025-05-23

### Added
- Per-tool risk scoring heuristic and console v1 (policy editor + live view).

## [0.6.0] - 2025-02-07

### Added
- Hot reload of policy files without dropping active sessions.

## [0.5.0] - 2024-09-20

### Added
- Session replay for incident forensics and a diff view between two sessions.
